# Launch checklist, Temida

Before posting anywhere:

- [ ] Decide whether to launch this one at all. The repo is private, and the app is built from Josh's own case. The landing at temida.jaybulb.com is already public, so a Product Hunt post pulls it into more view on purpose. That is worth a deliberate yes, not a default.
- [ ] If launching: pick a launch day (Tue–Thu, avoid the same week as another app launch)
- [ ] Pick a hunter (self-hunt is fine for a personal tool)
- [ ] Upload `launch/gallery/01-hero.png`, `02-signin.png`, `03-register.png` to the PH post, first image should be 01-hero
- [ ] Paste `producthunt.md` tagline/description/first comment into the PH new-post form
- [ ] Post `hn.md` to Hacker News as Show HN, ideally same morning as PH goes live
- [ ] Post `reddit.md` to r/SideProject; skip r/legaladvice unless flair rules clearly allow tool posts
- [ ] Thread `x.md` on X/Twitter once PH is live, link to the PH post not just the app
- [ ] Screenshots are real signin/register screens, not seeded demo data, fine as-is, no case content is shown
